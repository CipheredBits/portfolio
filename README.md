Web Technology Assignment – Website Recreation
This repository contains our Web Technology assignment where we recreated a given website based on the provided reference link.

How to View the Project

To see the recreated website:

1. Clone the repository

2. Open the folder in Visual Studio Code

3. Navigate to the project folder and open it with VS Code:

4. Launch with Live Server

Make sure you have the Live Server extension installed in VS Code.

Right-click on the index.html file and select "Open with Live Server".

The website will open in your default browser.
